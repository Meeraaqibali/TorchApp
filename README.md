# ⚡ Torch Pro

A beautiful, modern, and lightweight flashlight application built with Flutter. 

## ✨ Features

- **🔦 Flashlight Mode:** Quickly toggle your device's camera flash on and off.
- **📱 Screen Light Mode:** Turn your screen into a bright white light with an adjustable brightness slider.
- **💤 Blink Mode:** Flash your camera light at customizable speeds (50ms to 1000ms).
- **🎨 Modern UI:** A clean, dark-themed interface designed for easy one-handed use.
- **🔋 Keep Awake:** Prevents the screen from sleeping while the app is active.

## 🛠️ Built With

- [Flutter](https://flutter.dev/) - UI Toolkit
- [Dart](https://dart.dev/) - Programming Language
- [torch_light](https://pub.dev/packages/torch_light) - Flashlight control
- [screen_brightness](https://pub.dev/packages/screen_brightness) - Screen brightness control
- [wakelock_plus](https://pub.dev/packages/wakelock_plus) - Keep screen awake

## 🚀 How to Build

This project uses GitHub Actions to automatically build the APK. 
1. Push any changes to the `main` branch.
2. Go to the **Actions** tab in this repository.
3. Download the `torch-app-release-apk` artifact.

## 📲 Installation

1. Download the APK artifact from the GitHub Actions tab.
2. Extract the `.zip` file on your Android device.
3. Tap the `app-release.apk` file to install.
4. *Note: You may need to enable "Install from Unknown Sources" in your phone's settings.*
